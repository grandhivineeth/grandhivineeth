## Featured Projects

### 🧠 [EyeForBlind](https://github.com/grandhivineeth/EyeForBlind)
Deep learning model that explains image contents as speech using caption generation with an **attention mechanism** on the Flickr8K dataset. Combines CNN + LSTM with Bahdanau attention.

### ✋ [GestureRecognition](https://github.com/grandhivineeth/GestureRecognition)
CNN-based gesture recognition model built to classify hand gestures in real time. Explores Conv3D and transfer learning approaches for video sequence classification.

### 🤖 [ANN Implementation](https://github.com/grandhivineeth/ANN_Implementation)
From-scratch Artificial Neural Network tackling a **customer churn classification** problem — covers forward propagation, backpropagation, and hyperparameter tuning.

### 🔁 [RNN Implementation](https://github.com/grandhivineeth/RNN_Implementation)
Recurrent Neural Network built for **IMDB sentiment classification** — explores vanishing gradient challenges and LSTM-based solutions for sequential data.
